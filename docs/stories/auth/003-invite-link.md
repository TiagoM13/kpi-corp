## Cadastro via link de convite

## 📋 Descrição

Como membro convidado, quero me cadastrar através de um link enviado pelo Admin para criar minha conta e acessar a plataforma.

## ✅ Critérios de Aceite

- [ ]  Link de convite é único e tem prazo de expiração (48h)
- [ ]  Formulário de cadastro solicita: nome, cargo e senha
- [ ]  E-mail já vem preenchido a partir do link
- [ ]  Após cadastro, membro é redirecionado para seu Dashboard
- [ ]  Link expirado ou já usado exibe mensagem de erro clara
- [ ]  Conta criada com perfil MEMBRO automaticamente

## 📌 Informações

- Épico: Auth & Acesso
- Perfil: Membro
- Prioridade: Alta
- Fase: MVP
