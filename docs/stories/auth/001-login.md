## Login de usuário

## 📋 Descrição

Como usuário, quero fazer login com e-mail e senha para acessar a plataforma com meu perfil correto.

## ✅ Critérios de Aceite

- [ ]  Campo de e-mail e senha obrigatórios
- [ ]  Exibe mensagem de erro para credenciais inválidas
- [ ]  Redireciona Admin para o Dashboard Admin após login
- [ ]  Redireciona Membro para o Dashboard do Membro após login
- [ ]  JWT gerado e armazenado com segurança (httpOnly cookie ou localStorage)
- [ ]  Sessão expira após inatividade definida

## 📌 Informações

- Épico: Auth & Acesso
- Perfil: Admin / Membro
- Prioridade: Alta
- Fase: MVP
